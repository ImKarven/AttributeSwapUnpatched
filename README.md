# Attribute Swap Unpatched
As you may know, in version 26.1.2 pre-release 2, Mojang has patched **attribute swapping**. It is a technique commonly used in the PvP community to gain advantage by quickly switching items in their hotbar to apply attributes of an item to another.

This bug was discovered a few years ago and it changed modern PvP a lot. The removal of this bug from Mojang got many backlashes from the community. Thus, I created this mod to revert patches Mojang made to this bug and let players continue using attribute swap.

This mod is client-sided, you only need to install this mod on your client. Mojang only made patches to the client. Meaning the vanilla server still accepts attribute swaps if the client does so. Certain servers may block attribute swap on their side (For example, a Paper server disables attribute swapping by default). This also means that you **might get punished for cheating** if the server you are playing does not allow this mod.
